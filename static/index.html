Errors are not saved yet

The WhatsApp agent doesn't save its errors today. It will start saving them with the next agent update, and they will show here from then on.
  • Zoho or MenaMe rejected a request (wrong field or filter, token or connection trouble)
  • Claude API errors (rate limit, overloaded, timeout)
  • Answers cut off at the token limit, or given up after too many steps
  • Any other crash in the app
